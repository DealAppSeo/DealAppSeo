# Sean Goodwin

I build tools that let people check what their AI tells them before they act on it.

## Start here
- **[AIdeaGuy](https://aideaguy.dev)**: practical ways to get more out of AI. ([repo](https://github.com/AIdeaGuy/aideaguy))
- **[TrustShell](https://trustshell.dev)**: a portable trust layer for AI agents. ([repo](https://github.com/DealAppSeo/trustshell))

## The Trust projects
The current list, kept up to date automatically, is at **[trustshell.dev/ecosystem](https://trustshell.dev/ecosystem)**. Repositories are included when they carry the `trust-ecosystem` topic.

Main ones:
- [`repid-engine`](https://github.com/DealAppSeo/repid-engine): behavioural reputation scoring (RepID) for agents.
- [`hyperdag-protocol`](https://github.com/DealAppSeo/hyperdag-protocol): the interface kernel and defaults.
- [`hyperdag-proof-verifier`](https://github.com/DealAppSeo/hyperdag-proof-verifier): verify RepID proofs in your browser.
- [`example-agent`](https://github.com/DealAppSeo/example-agent): a small agent that fact-checks before it answers.
- [`trust-commons`](https://github.com/DealAppSeo/trust-commons): open conversation about safe, ethical AI.
